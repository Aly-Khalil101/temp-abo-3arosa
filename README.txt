أبو العروسة — Version 1.3
========================

التعديلات في هذه النسخة
----------------------
- استبدال عبارة النموذج التجريبي بتوقيع: «صُنعت بكل الحب» ثم اسم علي أحمد خليل و«صِــلَة لدعوات الأفراح والمناسبات الإلكترونية» ورقم التواصل.
- جعل رقم الهاتف رابط اتصال مباشر.
- زر الموسيقى أصبح تشغيل/إيقاف: يبدأ الصوت تلقائيًا مع الضغط على ختم الباب، ويمكن إيقافه وإعادة تشغيله من الزر الدائري.
- عند إيقاف الموسيقى، يتوقف الصوت مع الاحتفاظ بموضعه؛ وعند إعادة التشغيل يكمل من الموضع نفسه.
- أضيف متغير واضح في JavaScript للتحكم في توقيت بداية الموسيقى.
- لا توجد ملفات MP3 مرفقة في هذه الحزمة، حسب الطلب.

إضافة ملفات الصوت
-----------------
ضع ملفي الصوت داخل مجلد assets الموجود بجوار index.html:
1. instrumental-demo.mp3  ← ملف الموسيقى الخاص بك.
2. door-opening.mp3       ← مؤثر فتح الباب الخاص بك.

لا تغيّر أسماء الملفات إلا إذا غيّرت المسارات في index.html.

التحكم في توقيت الموسيقى
------------------------
في ملف script.js ابحث عن هذا السطر:

const MUSIC_START_DELAY_MS = 0;

- القيمة 0 تعني أن الموسيقى تبدأ مباشرة عند الضغط على ختم الباب. وهذا الخيار الأكثر موثوقية مع قيود التشغيل التلقائي في المتصفحات.
- لو أردت تجربة تأخير نصف ثانية، غيّرها إلى 500؛ ولثانية واحدة، إلى 1000.
- تنبيه: قد تمنع بعض المتصفحات تشغيل الصوت إذا تأخر استدعاء play() عن ضغطة المستخدم. لذلك اترك القيمة 0 إن كانت الأولوية للتشغيل الموثوق، أو جرّب التأخير على المتصفح المستهدف.

التشغيل
-------
افتح index.html في المتصفح بعد إضافة ملفي الصوت. يمكن نشر الملفات نفسها على GitHub Pages أيضًا.

ملاحظة تعليمية عن زر الموسيقى
-----------------------------
JavaScript يستخدم backgroundMusic.paused لمعرفة حالة الصوت:
- إذا كانت paused تساوي true، يستدعي play() لبدء/استكمال الموسيقى.
- وإلا يستدعي pause() لإيقافها مؤقتًا.
لا نعيد currentTime إلى الصفر عند الإيقاف، ولذلك تستكمل الموسيقى من الموضع الذي توقفت عنده. أما زر «إعادة تجربة فتح الدعوة» فيعيدها إلى البداية.

درس SVG
-------
في index.html ابحث عن <svg class="emblem-ring" viewBox="0 0 100 100" ...>.
- viewBox="0 0 100 100" يحدد مساحة الإحداثيات الداخلية للرسم.
- path يرسم الشكل، والخاصية d تحتوي أوامر الرسم.
- M تنقل القلم إلى نقطة، وL ترسم خطًا، وC ترسم منحنى، وZ تغلق الشكل.
- stroke-width يغيّر سُمك الخط، وليس حجم الشكل.

أبعاد الختم تتحكم بها متغيرات CSS ضمن .family-emblem في style.css:
- --emblem-width و--emblem-height: حجم مساحة الختم بالكامل.
- --rosette-scale-x: عرض الزخرفة الداخلية.
- --rosette-scale-y: ارتفاع الزخرفة الداخلية.
جرّب تغيير قيمة واحدة كل مرة حتى تستطيع ملاحظة تأثيرها بوضوح.
